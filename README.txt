ROCK STRIKE LABS WEBSITE
========================
Open index.html in any modern browser.

Files:
- index.html
- about.html
- software.html
- services.html
- contact.html
- css/styles.css
- js/main.js
- assets/ brand images and contact QR

This version is static: no build process, package manager, framework, database, or server is required.

Contact form:
The form opens the visitor's default email client using mailto:.
For a future hosted form that submits without opening an email app, connect a form service or backend.

Deployment:
Upload the complete folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, traditional web hosting, etc.).
